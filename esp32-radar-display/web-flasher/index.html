LD2450 Radar Display

Install the radar display firmware on an ESP32-DevKitC-32E from your browser, with nothing to install.

Before you click Install

  1. Use Chrome or Edge on a Windows, Mac or Linux computer. Phones and Firefox can't do this.
  2. Plug the ESP32 into the computer with a micro-USB data cable (some cables only charge).
  3. On Windows, check Device Manager → Ports (COM & LPT) shows Silicon Labs CP210x … (COMx). If it doesn't, install the CP210x driver from the repository (docs/hlk-ld2450/common software/Serial port driver.zip) and replug.
  4. Close anything else that might be using the port (PlatformIO serial monitor, Arduino IDE).
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.
Flashing needs a secure (https) page. Open this page from its GitHub Pages address.

After you click Install

  1. Pick the port named CP210x (or USB to UART) and click Connect.
  2. Choose Install and confirm. The ESP32 is erased and the firmware written, which takes about a minute.
  3. If it hangs at Connecting, hold the Boot button on the ESP32 until progress starts.
  4. When it finishes, press the EN (reset) button. The screen should show "LD2450 RADAR", then the green radar view.
